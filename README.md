# グラス歩数計 — Glass Pedometer

Meta Ray-Ban Display 用の歩数計 WebApp。加速度センサーでリアルタイムに歩数をカウントし、目標歩数に対する達成率をリング表示で確認できます。

- **ライブURL**: https://glass-pedometer.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / 静的サイト）

## 特徴

- **加速度センサーでリアルタイム歩数検出** — `devicemotion` の加速度データからピーク検出アルゴリズムで歩行動作を判定しカウント
- **目標達成率をリング表示** — 中央に歩数、外周のリングで目標歩数に対する進捗を可視化。目標達成時はリングの色が変わり、達成トーストが表示される
- **距離・消費カロリーを自動推定** — 歩幅0.7m・1歩あたり0.04kcalの概算で表示
- **目標歩数はD-padで自由設定** — 設定画面で ±100／±1000 単位で調整、localStorageに保存
- **日付が変わると自動リセット** — 当日の歩数は日付をまたぐと自動的に0に戻る
- **センサーが使えない環境では自動でデモモード** — モーションイベントが一定時間得られない場合、自動的にシミュレーション歩数に切り替えてUIを確認できる
- すべてタップ＋D-padスライドだけで往復可能

## 操作方法

| 画面 | 操作 |
|------|------|
| ホーム画面 | 「計測開始 ▶」をタップして計測開始／一時停止。「設定 ⚙」で目標歩数の設定画面へ |
| 設定画面 | ↑↓←→ で −1000／−100／＋100／＋1000 ボタンを選択しタップで目標歩数を調整。「今日の歩数をリセット」で当日の記録をクリア。「← もどる」でホームへ |
| PC確認用 | Escape で戻る（グラスの戻るジェスチャーは使用不可のため補助のみ） |

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=glass-pedometer&appUrl=https%3A%2F%2Fglass-pedometer.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラス歩数計`、URL `https://glass-pedometer.vercel.app` を入力。
